# goldbachJasmin

The `.jazz` files of the directories `src` and `src_sse` of goldbachJasmin
(commit e66b2d4), a verification of the Goldbach conjecture written in
Jasmin by Laurent Théry, the user who asked for this experiment: his own
code, with no license file, included with the author's agreement. Copied
unchanged; all of them parse.

Used as a test set for error recovery: `recov.py fuzz` damages them and
checks what is recovered.
